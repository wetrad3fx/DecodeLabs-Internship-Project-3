SQL Data Analysis Project

Project Overview

This project analyzes an order dataset using SQL queries to extract useful business insights.

Objectives

- Retrieve data using SELECT
- Filter data using WHERE
- Sort results using ORDER BY
- Group data using GROUP BY
- Perform aggregations using COUNT, SUM, and AVG
- Extract meaningful insights from the dataset

Tools Used

- SQL
- Excel
- VS Code


Dataset

The dataset contains information about orders, products, customers, payment methods, order status, coupons, referral sources, and total prices.

Analysis

The SQL analysis includes:

- Total number of orders
- Total revenue
- Average order value
- Product revenue analysis
- Payment method analysis
- Coupon analysis
- Referral source analysis
- Order filtering and sorting
